FILES
- index.html: all five website views and content
- style.css: design, responsive layout and animations
- script.js: navigation, music controls and interactions
- images/: upload your 13 photographs here

BACKGROUND MUSIC
Add one audio file named birthday-music.mp3 inside the music folder.
The music begins after the visitor clicks OPEN YOUR SURPRISE on the first page.
It continues seamlessly while moving between the five views because the website changes views without reloading the page.
The floating Music button can pause or resume playback.
Use a music file you have permission to use.

PUBLISH WITH GITHUB PAGES
1. Create a new GitHub repository.
2. Upload index.html, style.css, script.js, README.txt, and the images and music folders.
3. Put the photographs in images/ and the music file in music/.
4. Open the repository Settings, then Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Select the main branch and the root folder, then Save.
7. Wait for GitHub Pages to publish the site. Open the URL shown in Settings > Pages.

NOTES
- The five sections are separate full-screen page views with their own navigation and browser history, but they live in one HTML page so background music is not interrupted by page reloads.
- Google Fonts are loaded online. If the visitor is offline, the site falls back to installed serif and sans-serif fonts.
- The site is mobile responsive.
